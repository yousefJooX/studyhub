# Security policy

StudyHub stores people's notes, files and passwords, so security reports are taken seriously.

**Please report vulnerabilities privately** through GitHub: *Security → Report a vulnerability* on this repository. Do not open a public issue.

Include what you found, how to reproduce it, and the impact you expect. You should get a reply within a week. Once a fix is released you will be credited in the release notes unless you prefer otherwise.

Only the latest commit on `main` is supported. The protections already in place are listed in the README's *Security* section, and `tests/security_check.py` runs the attack checks against a local instance.
