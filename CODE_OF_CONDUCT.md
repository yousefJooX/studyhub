# Code of Conduct

StudyHub follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, especially with students who are contributing for the first time. Harassment, insults and personal attacks are not accepted, in Arabic or in English.

Report problems privately to the maintainer through GitHub ([@yousefJooX](https://github.com/yousefJooX)). Reports are kept confidential.
