# StudyHub walkthrough: transcript (Arabic)

**00:00**  StudyHub: مساحتك للمذاكرة. موادك ومهامك وجدولك ونوتسك في مكان واحد.  
**00:06**  أول ما تفتح الموقع، اعمل أكونت. بياناتك خاصة بيك، ومحدش يقدر يشوفها غيرك.  
**00:15**  لو انت من الكلية، اكتب كود الكلية. الكود في جروب الدفعة، وبيفتحلك أرشيف الكلية وتاسكات سنتك.  
**00:25**  دي الصفحة الرئيسية. يومك كله قدامك: المحاضرات، المهام، والديدلاينز القريبة.  
**00:30**  ضيف موادك. من «المواد» دوس إضافة واكتب اسم المادة.  
**00:43**  وبنفس الطريقة باقي المواد. مواد الكلية، أو أي كورس برّه الكلية.  
**00:49**  الجدول الأسبوعي. المحاضرات والسكاشن واللابات، ومواعيد مذاكرتك كمان.  
**00:54**  المهام والديدلاينز. كل مهمة ليها مادة، ويوم هتعملها فيه، وديدلاين.  
**00:59**  والموقع يفكّرك قبل الديدلاين. قبلها بيوم، و١٢ ساعة، وساعة، على الموبايل والكمبيوتر.  
**01:07**  تاسكات الكلية بتيجي لوحدها. أي assignment بينزل على قناة دفعتك بيتضاف لمهامك حسب سنتك وبرنامجك.  
**01:14**  ودي جت من قناة الدفعة. بالديدلاين والمادة ولينك البوست · البيانات من HNU Board بتاع مصطفى سيد.  
**01:20**  المساعد الذكي. أول مرة بيطلب منك API key مجاني، وده بياخد دقيقتين.  
**01:25**  هات key مجاني من Groq. افتح console.groq.com/keys ← Create API Key ← انسخ الـ key اللي بيبدأ بـ gsk_.  
**01:29**  الصقه هنا ودوس «حفظ وتجربة». الموقع بيتأكد إنه شغال، وبيحفظه مشفّر. محدش يقدر يشوفه.  
**01:38**  اكتبله زي ما بتكلم صاحبك. وهو يضيف التاسكات والمواعيد ويربطها بالمادة الصح.  
**01:50**  خلاص، اتضافوا. تاسكين بالديدلاين، وميعاد اللاب في الجدول.  
**01:58**  تايمر المذاكرة. افتح أي مهمة ودوس «ابدأ»، ووقتك بيتسجّل لوحده.  
**02:10**  نوتس Obsidian بتاعتك. ارفع فولدر النوتس أو ZIP منه من الإعدادات.  
**02:17**  المكتبة. الفولدرات بتتفتح وتتقفل زي Obsidian.  
**02:21**  النوتس بتظهر نضيفة. المعادلات والكود والـ callouts والجداول والـ diagrams.  
**02:28**  المراجعة الأسبوعية. ذاكرت كام ساعة، في أنهي مادة، وخلّصت إيه، وأيام الـ streak.  
**02:36**  تذكير بصوتك انت. سجّل فويس لكل مرحلة، ولما ييجي التذكير يشتغل صوتك.  
**02:40**  ولو معاك Claude. اعمل connector من هنا، وكلّمه عن مهامك ونوتسك من تطبيق Claude.  
**02:44**  الموقع عربي وإنجليزي. وعلى الموبايل: افتح اللينك واختار Add to Home screen.  
**02:58**  هات key مجاني للمساعد من Groq: افتح console.groq.com/keys وسجّل بحساب Google، دوس Create API Key، انسخ الـ key اللي بيبدأ بـ gsk_، والصقه في الإعدادات ← المساعد الذكي.  
**03:08**  بالتوفيق في المذاكرة! الموقع: study-joox-friends.loophole.site · الكود: github.com/yousefJooX/studyhub
